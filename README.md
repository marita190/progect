# Particle Filter for Robot Localization
## Описание проекта
Данный проект реализует фильтр частиц (Particle Filter) для оценки положения объекта, учитывая шумные измерения.

Алгоритм моделирует движение объекта и использует множество случайных частиц для приближенной оценки координат объекта.

Проект реализован на языке С и разделён для удобства на несколько файлов.

# Теория
## Particle Filter
Фильтер частиц - это вероятностный алгоритм оценки состояния системы, который использует:

  1. множество частиц,
     
  2. веса вероятностей,
     
  3. шум движения,
     
  4. шум измерений,
     
  5. ресемплирование.
     
маааа

Каждая частица представляет возможное состояние объекта.

## Gaussian Noise

## Используемые формулы

Состояние системы:

$$
x_k = x_{k-1} + u_k + w_k
$$

Измерение:

$$
z_k = x_k + v_k
$$

ESS:

$$
ESS = \frac{1}{\sum_{i=1}^{N} w_i^2}
$$
