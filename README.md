# Particle Filter for Robot Localization
## Описание проекта
Данный проект реализует фильтр частиц (Particle Filter) для оценки положения объекта, учитывая шумные измерения.

Алгоритм моделирует движение объекта и использует множество случайных частиц для приближенной оценки координат объекта.

Проект реализован на языке С и разделён для удобства на несколько файлов.

# Теория
## Particle Filter
Фильтр частиц - это вероятностный алгоритм оценки состояния системы, который использует:

  1. множество частиц,
     
  2. веса вероятностей,
     
  3. шум движения,
     
  4. шум измерений,
     
  5. ресемплирование.
     

Каждая частица представляет возможное состояние объекта.

## Gaussian Noise

Для моделирования случайного шума используется нормальное распределение.

Шум генерируется с помощью преобразования Бокса-Мюллера (это метод генерации пары независимых случайных чисел с гауссовским распределением из двух независимых случайных чисел с равномерным распределением на интервале (0, 1]).

## ESS (Effective Sample Size) используется для оценки степени вырождения частиц.
ESS используется для определения вырожденнных частиц (это частицы, у которых вес практически равен нулю).
Если ESS становится слишком маленьким, это означает, что значительная часть частиц имеет почти нулевой вес и перестаёт влиять на итоговую оценку.

По значению ESS определяется нужно ли ресемплирование. Ресемплирование - это процесс замены текущего набора взвешенных частиц новым набором частиц с равными весами, где новые частицы выбираются из текущего набора с вероятностью, пропорциональной их весам. Частицы с большими весами копируются, а частицы с маленькими весами удаляются. 

## Используемые формулы

Состояние системы:

$$
x_k = x_{k-1} + u_k + w_k
$$

Измерение:

$$
z_k = x_k + v_k
$$

ESS:

$$
ESS = \frac{1}{\sum_{i=1}^{N} w_i^2}
$$

## Сборка проекта
Сборка основной программы осуществляется с помощью make.

Make - это утилита, которая сама вызывает компилятор и собирает программу из исходников, избавляя от ручного ввода длинных команд (вместо того, чтобы писать gcc main.c filter.c -lm -o program, вы просто пишете make, и Make сам знает, какие файлы компилировать, в каком порядке и как их связывать).
